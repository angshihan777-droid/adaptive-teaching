# 自适应项目教学

面向中文初学者的 Codex 教学 Skill。

它帮助学习者从真实项目中的功能现象出发，理解概念、追踪跨文件调用、运行验证并练习项目面试。重点不是“把代码讲一遍”，而是让学习者知道：谁触发了什么、数据经过哪里、为什么这样设计、失败时去哪里找。

## 核心特色

- **概念先行**：先说明眼前问题和通用机制，再用项目代码做证据。
- **顺着调用深入**：当前函数依赖另一个函数、配置或文件时，沿真实逻辑继续进入，不人为截断。
- **局部串联**：每次深入到一个可收束的位置，都用“这次我们串起来了什么？”把新知识带回原来的主线。
- **证据驱动**：运行结果、日志、截图、测试和学习者复述共同决定是否通关。
- **边界清楚**：精确说明本次学到的函数和职责，不把“看过一个文件”说成“学完整个文件”。
- **面向面试**：问题来自当前源码和调用链，覆盖概念、项目实现、调试和设计追问。

## 一节课怎么进行

```text
确定一个知识点
    -> 从可观察行为提出问题
    -> 用白话讲清通用概念
    -> 给出最小例子
    -> 沿真实源码调用链深入
    -> 串联已经学到的文件和职责
    -> 运行、观察或测试
    -> 学习者复述与项目面试
```

每个知识点依次经过：

| 阶段 | 目标 |
|---|---|
| 教学阶段 | 理解问题、概念、因果关系和边界 |
| 源码阶段 | 把概念对应到真实文件、函数、数据和失败路径 |
| 面试阶段 | 用自己的话解释，并回答基于项目的追问 |

节点内的知识点完成后，再进行节点总结，回顾完整链路和工程判断。

## 典型的局部串联

例如正在学习启动回调：

```text
_on_startup()
    -> 调用 init_db()
    -> init_db() 需要 settings.db_path
    -> 进入配置文件理解路径来源
    -> 回到 init_db() 继续数据库操作
```

深入结束后，课堂会用简洁的 Markdown 说明：

- 为什么要进入下一个函数或文件；
- 这次具体连起了哪些职责；
- 回到主线后，现在能解释什么；
- 哪些内容暂时没有学习；
- 下一步从哪一行继续。

## 安装

使用 Git 克隆到 Codex Skills 目录：

```bash
git clone https://github.com/angshihan777-droid/adaptive-teaching.git \
  "$CODEX_HOME/skills/adaptive-teaching"
```

如果环境已经设置了 Codex Skills，也可以将仓库放入：

```text
~/.codex/skills/adaptive-teaching/
```

## 使用方式

开始一门新课：

```text
使用 $adaptive-teaching，读取我的学习计划和当前进度，开始学习这个项目。
我是初学者，请先从可观察的功能行为讲起，再进入真实源码。
```

继续上一节：

```text
使用 $adaptive-teaching，读取当前学习进度，继续上次停下的调用链。
请顺着真实代码深入，并在每次深入后用“这次我们串起来了什么？”收束主线。
```

适合提供给 Skill 的材料包括：学习计划、进度表、源码路径、运行日志、接口地址和截图。

## 适用场景

- 学习真实的后端、前端、HTTP、数据库或 Agent 项目；
- 从浏览器、接口或终端现象追踪到源码；
- 理解跨文件调用、数据转换和应用生命周期；
- 通过正常路径和失败路径练习调试；
- 准备能引用源码证据的项目面试。

## 教学边界

本 Skill 不会：

- 用目录清单或逐行翻译替代概念教学；
- 要求学习者猜尚未讲过的完整因果链；
- 在一节课里同时深挖多个技术系统；
- 把“代码能运行”直接当作“学习者已经理解”；
- 擅自修改学习计划、课程笔记或项目顺序。
