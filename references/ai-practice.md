# AI-Assisted Practice

Use only after the learner has understood the relevant concept.

1. Ask the learner to describe the implementation task without supplying a polished prompt.
2. Ask what the AI could misunderstand, omit, or expand.
3. Review the first proposal for current context, concrete goal, inputs, non-goals, permitted files, technical and safety constraints, uncertainty handling, and acceptance evidence.
4. Let the learner decide whether the proposal is sound.
5. Implement the smallest slice, run it, test normal/error/edge cases, and compare observed behavior with AI claims.

Do not teach prompt length as a goal. Use real omissions and failures as the material for improving the task description.
