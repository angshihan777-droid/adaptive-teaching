# Task Anchor

Use this to keep a multi-turn lesson aligned with the learner's current goal. A workflow describes how this kind of lesson usually proceeds; the task anchor describes this lesson instance.

```markdown
## Current task anchor

Goal: <what the learner should understand or verify in this lesson>
Boundaries: <what this lesson does not teach>
Done when: <what the learner can explain, run, or verify>
Current evidence: <project observation, code evidence, or learner explanation>
Open uncertainty: <what is still unknown>
Next natural step: <why the next lesson follows>
```

Refresh the anchor when the learner changes topic, new evidence invalidates an assumption, or the lesson would otherwise expand into a neighboring system.
